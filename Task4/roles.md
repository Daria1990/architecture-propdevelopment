# Роли доступа к кластеру Kubernetes

**Автор:** Дарья Палюлина
**Дата:** 2026-09-20

Кластер делится на пространства имён по доменам компании: `sales`, `zhku`, `finance`, `data`.

| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| `platform-admin` (ClusterRole) | Всё в кластере | DevOps-инженеры (`platform-admins`) |
| `developer` (Role в домене) | Менять сервисы своего домена. Без секретов | Разработчики и эксплуатация домена (`sales-developers`, `zhku-developers`, …) |
| `viewer` (ClusterRole) | Только просмотр, без секретов | Менеджеры, аналитики, владельцы продукта (`viewers`) |
| `secrets-reader` (ClusterRole, привилегированная) | Просмотр секретов | Специалист по ИБ (`security`) |

Пользователи для проверки:

| Пользователь | Группа | Что может |
| --- | --- | --- |
| `devops-admin` | `platform-admins` | всё в кластере |
| `sales-dev` | `sales-developers` | деплой только в `sales` |
| `manager` | `viewers` | смотреть везде, без секретов |
| `security-officer` | `security` | смотреть везде + секреты |
